# Выбор полного стека Rivect

Дата: 2026-09-08. Решение root: Rust; ADR: [0001-native-stack.md](../docs/adr/0001-native-stack.md). Основание: master §§4.1–4.4/8.2/10.14/17 и spec REQ-002. Исследованы Rust, Go и TypeScript Node/Bun; сравнительных реализаций, установок зависимостей и собственных runtime benchmarks не было.

Выбор опирается на прямое использование Rust-библиотек поиска и AST вместе с нативным TUI, локальным хранилищем и одним toolchain собственного кода. Он не доказывает превосходство по latency, RAM, качеству или времени разработки. Go и TS с подготовленными release-артефактами тоже способны работать без сборки у пользователя; это допустимые альтернативы, а не нарушители ТЗ по определению.

## Источники и границы проверки

Registry/release metadata собраны исследовательским проходом StackEvidence; root сверил load-bearing APIs ниже по versioned docs/source. Досье BoundaryEvidence отдельно проверяло протоколы, OS isolation и SQLite. Метаданные подтверждают существование/версию/заявленные зависимости, не совместную сборку и не безопасность всей транзитивной цепочки. Финальный lockfile, features, build scripts и advisory scan входят в первый admission перед установкой/сборкой. Источники без версии либо только поисковые выдержки не используются для положительного support claim.

Здесь выбраны библиотечные engines. Для CPU parsing/indexing нужен bounded worker, чтобы locality не блокировала input. Известный query kind выбирается кодом, а не вторым LLM.

## Опубликованные замеры

[Bun SQLite docs](https://bun.com/docs/runtime/sqlite) приводят vendor-сравнение 3–6x с better-sqlite3 на Northwind, M1/macOS 12.3.1, 2022. Это не независимое сравнение современных целых комплектов и не измерение Rivect. [ripgrep](https://github.com/BurntSushi/ripgrep) содержит инструкции/benchmarks text search; их corpus/options необходимо сохранять при интерпретации, они не оценивают TUI, MCP или durable task state.

В bounded-поиске не найден сопоставимый полный Rust/Go/Node/Bun комплект на одной нагрузке. Вторичные johal.in цифры и оценки размера бинарника из черновика исключены: они не дают primary/comparable proof для выбора. Ни startup speedup, ни размер, ни ускорение build этим документом не заявляются. [performance-budgets.md](performance-budgets.md) задаёт последующий baseline и frozen пределы на настоящей production-базе.

## Причины выбора и риски

Tournament Rust vs Go: решающий критерий — интеграция уже выбранных text/path/AST engines без дополнительных Rust↔Go adapters/helper protocols при одном native application toolchain. Go выигрывает простотой ряда stdlib APIs; Rust принимает Cargo+C build цену. Tournament Rust vs TS/Bun: решающий критерий — владение полным native release graph без дополнительной Node/Bun ABI/prebuild матрицы. TS удобен своими SDK, но это не доказанное сокращение полной стоимости реализации; работоспособная TS-поставка возможна.

До положительного support/release verdict обязательны: resolve/pin совместимого dependency graph без дублирующих Tree-sitter/keyring major; review исполняемых build scripts и licences/SBOM; actual SQLite version/FTS5; terminal/input/cancel и OS isolation positive+negative; credential roundtrip/absence/ambiguity; actual MCP dialect/continuation; installed layout на macOS/Linux; performance baseline и полный eval. Эти исполнения относятся к выбранной production-базе, не к новому сравнению языков. Недоступная платформа/аккаунт получает BLOCKED/NOT_RUN, не PASS.

## Наблюдение macOS sandbox primitive

`man sandbox-exec` подтвердил installed DEPRECATED utility. Неполный deny-default probe на owned temp files дал SIGABRT во всех четырёх read/write controls: защитный PASS отсутствует. Различающий `sandbox-exec -p '(version 1)(allow default)' /usr/bin/true` дал exit0; targeted-deny profile затем дал allowed-read0, denied-read1/EPERM, allowed-write0, denied-write1/EPERM, forbidden file не создан. Все temporary resources удалены после проверки; пользовательские данные не использованы.

Это доказывает доступность native confinement primitive и ошибочность первой bootstrap-profile гипотезы, не безопасность Rivect, no-direct-egress, deny-default полноту или Linux. Production profile conformance и восстановление его bootstrap allowance — HZN-004, SLICE-003. Diagnostic allow-default profile в продукт не переносится.
